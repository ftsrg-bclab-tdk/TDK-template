# License texts

The root [LICENSE](../LICENSE) defines which original template contributions use
each license and lists inherited-material exceptions. These files do not replace
the presentation's AVM/OFL notices or notices embedded in inherited source files.

- `MIT.txt` uses the [SPDX MIT text](https://spdx.org/licenses/MIT.html), with the
  template author's copyright line.
- `CC-BY-4.0.txt` is the unmodified English text downloaded from the
  [SPDX license-list mirror](https://raw.githubusercontent.com/spdx/license-list-data/main/text/CC-BY-4.0.txt)
  on 2026-11-04. The [canonical Creative Commons legal code](https://creativecommons.org/licenses/by/4.0/legalcode.en)
  was also checked; direct command-line download of its text endpoint returned 403.

Include the relevant license texts, root scope notice and component-specific
attributions when exporting reusable template material.
